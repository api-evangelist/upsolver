# Upsolver

> Upsolver is a cloud data ingestion and lakehouse pipeline company whose SQLake platform lets teams build and deploy streaming data pipelines with familiar SQL. Upsolver was acquired by Qlik and the product now continues as Qlik Open Lakehouse; the standalone Upsolver (SQLake) product is legacy, with docs maintained under Qlik's help site.

Programmatic access to Upsolver (SQLake) uses a personal API token generated in the SQLake console (Settings > API Tokens) plus an account-specific API URL. First-party Python tooling — a DB API 2.0 SDK, a CLI, and a dbt adapter — talks to the Upsolver API service over HTTP. No OpenAPI, AsyncAPI, or llms.txt is published by the provider.

## SDKs & Tools

- [upsolver-sdk-python (PyPI)](https://pypi.org/project/upsolver-sdk-python/): Python DB API 2.0 connector for SQLake SQL over the Upsolver HTTP API
- [upsolver-cli (PyPI)](https://pypi.org/project/upsolver-cli/): interactive SQL shell for the Upsolver API service
- [dbt-upsolver (PyPI)](https://pypi.org/project/dbt-upsolver/): dbt adapter for Upsolver
